One word for my Wi-Fi: **Teenager** — 8 characters. Home Wi-Fi behaves exactly like a teenager: it works perfectly until you actually need it, then vanishes into its room, ignores you, and only comes back out on its own terms. The program writes the word to `/output/entry.txt` — deterministic, Node stdlib only, no network.

## Run it

```sh
node main.ts
```
